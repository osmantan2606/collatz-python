# Collatz Dizisi (Python)

Kullanıcıdan pozitif bir tam sayı alıp Collatz dizisini 1'e ulaşana kadar yazdıran ve toplam adım sayısını gösteren program.

Bu proje, "Automate the Boring Stuff with Python" kitabının exception handling bölümündeki bölüm sonu projesine dayanır. Kodu kendim yazdım ve kullanıcıya tekrar soran girdi doğrulama ile adım sayacını ekledim.

## Öğrendiklerim
- Fonksiyon yazma, `print` ve `return` farkı
- `while` döngüsü ve sonsuz döngü hatasını bulup düzeltme
- `try / except` ile `ValueError` yakalama
- Girdi doğrulama (metin, ondalıklı sayı, 0 ve negatif sayı)

## Çalıştırma
python collatz.py
